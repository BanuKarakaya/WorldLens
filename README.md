# 📰 World Lens

**World Lens** is a sleek and modern iOS news project that allows users to stay updated with breaking news, explore stories by category, perform keyword-based searches, and read article summaries with direct access to full content links.

  ## ✨ Features
📍 Home Page: Displays the latest breaking news with daily updates
🗂️ Categories Page: Browse news by category (e.g., Technology, Sports, Health, Economy)
🔍 Search: Find news articles by keywords using a responsive search bar
📄 Detail Page: Read a short summary and access the full article via external link
⚡️ Modern UI: Fast and intuitive user interface with smooth interactions

  ## 🛠 Technologies & Implementations
  ### 🧠 Memory Management
  - Applied best practices to prevent memory leaks and improve app performance

  ### 🔁 Communication Mechanisms
  - Used `Delegates` and `NotificationCenter` for interaction between components

  ### 🧱 Architecture
  - Built with MVVM (Model-View-ViewModel) pattern for modularity and testability

  ### 🧩 Development Principles
  - Implemented **Dependency Injection** to improve maintainability and modularity
